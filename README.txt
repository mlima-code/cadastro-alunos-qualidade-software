# Cadastro de Alunos

Sistema web desenvolvido para a disciplina de Qualidade de Software.

Funcionalidades:
- Cadastro de alunos
- Validação de dados
- Matrícula duplicada bloqueada
- Edição e exclusão
- Persistência com LocalStorage

Tecnologias:
- HTML
- CSS
- JavaScript

Execução:
Abrir o arquivo index.html no navegador.
